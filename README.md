# P001: AI-BIM Integration for Early-Stage Building Energy Performance Prediction — A Scoping Review

- **Project ID:** `P001`
- **Status:** `Protocol` (Registered November 2026)
- **Principal Investigator:** Hadjer Bessai (`contact@built-environment-ai.org`)
- **Organization:** [Built Environment AI Initiative](https://built-environment-ai.org)
- **Reporting Standard:** PRISMA-ScR (Preferred Reporting Items for Systematic Reviews and Meta-Analyses Extension for Scoping Reviews)

## Overview

This repository hosts the registered scoping review protocol, database search strings, PRISMA-ScR screening logs, and structured data extraction dataset examining how Artificial Intelligence (AI) and Machine Learning (ML) are integrated with Building Information Modelling (BIM) for early-stage building energy performance prediction.

## Repository Structure

```text
p001-ai-bim-energy-scoping-review/
```
